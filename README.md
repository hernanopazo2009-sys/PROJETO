# Toda Vida Merece Respeito

Site estático do projeto de extensão sobre ética, diversidade, direitos humanos e proteção animal.

## Publicar com GitHub Pages

1. Crie um repositório público no GitHub e envie os arquivos deste projeto.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` (ou `master`) e a pasta `/ (root)`.
4. Salve. O GitHub exibirá o endereço público do site na própria página de configurações.

O site usa apenas HTML e CSS e pode ser hospedado diretamente pelo GitHub Pages. Antes de publicar, complete os campos marcados como “A definir” com as informações confirmadas da ação.
